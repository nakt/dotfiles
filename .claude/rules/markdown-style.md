# Markdown 作成ルール

## スタイル

- 見出しのレベルは 1 段ずつ下げ、飛ばさない（`#` の次は `##`）
- 強調（`**`）は本当に強調が必要な箇所のみに使う
- 絵文字は使わない（ユーザーが明示的に要求した場合を除く）
- 本文の段落は文の終わり（`。` `？` `！`）で改行し、1 文 1 行にする。文の途中では折らない（固定幅・見た目の都合でのハードラップはしない）。箇条書き項目・テーブルセル・見出し・フロントマターは対象外で、1 項目 1 行のまま書く

## Linter について

- markdownlint は PostToolUse hook が自動実行するため、同じ lint を二重に実行しない
- hook からの lint エラーフィードバックを受けたら、その内容に従って修正する
